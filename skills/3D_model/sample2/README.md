# 墨石公寓 Ink & Marble · 交互式 3D 公寓

按一张室内设计参考图设计的三室两卫公寓（12 × 10 m，层高 3.0 m）。参考图的语言是深色胡桃木饰面、白色大理石电视框、框下的暖色灯带和落地纱帘；客厅按参考图高细节还原，其余房间沿用同一套材料。按 `3D_model/README.md` 的流程，用 Machine、Anatomy、Hairline 三个技能分别完成 3D 模型、原理图和引导插图，再集成到一个页面。

## 打开方式

- **入口：`index.html`**，双击用浏览器打开（Chrome / Edge 最佳）。
- 3D 模型需要联网：three.js 0.170 来自 jsDelivr，字体来自 Google Fonts。测试台和样板盘可以离线运行。
- 三个可视化都能单独打开：
  - `machine/apartment.html`：公寓 3D 模型
  - `anatomy/daylight-bench.html`：日光系数测试台（深色版是 `daylight-bench-dark.html`）
  - `hairline/hairline-material-board.html`：材料样板盘（加 `?theme=dark` 用深色）
- 重新生成（在 `sample2/` 里运行）：
  - 3D 模型：改 `machine/src/apartment.js` 或 `machine/src/head.html` 后运行 `node machine/build.mjs`。它把 Machine kit（原样）、`shared/daylight.mjs` 和页面源码拼成一个自包含的 `apartment.html`。
  - 测试台：`node anatomy/build.mjs`，深色版加 `--dark`。
  - 样板盘：`node ../hairline/skills/hairline-create/build.mjs material-board.js`（在 `hairline/` 里运行）；检查用同目录的 `look.mjs`。
  - 数值只在 `shared/daylight.mjs` 一处定义；改了它，要重新生成 3D 模型和测试台。

## 每个技能做了什么

- **Machine**（`machine/`）：整套公寓的 3D 模型，真实尺寸（m），约 525 个零件、11.8 万个三角面。
  - 平面：客厅 29 m²、餐厅、开放厨房（岛台大理石瀑布边）、玄关（整面竖纹鞋柜）、走廊（电视墙背后的储物柜）、主卧 + 主卫、次卧、次卫。
  - 客厅按参考图：胡桃木竖向饰面板、3.0 × 1.38 m 大理石电视框（左侧黑钢搁板壁龛、书页对纹背板）、框下 2400 K 隐藏灯带、悬浮大理石地台、65 寸电视、1.4 × 2.7 m 黑钢框门洞、竖纹深色墙和对讲机、两面落地窗与波浪纱帘、1.52 m 六叶黑色吊扇、两条磁吸轨道 6 个射灯、东侧跌级天花灯槽、两组布艺沙发、大理石方块茶几、两只黑色木凳、落地灯。
  - 材质全部程序生成：大理石纹、胡桃木纹、竖纹凹凸、1200 × 600 抛光灰砖、橡木地板、条纹地毯、布艺（sheen）。
  - 交互：时间滑块（06:00–24:00）、四个灯光场景、纱帘（自动 / 拉上 / 拉开）、电视墙饰面（胡桃木 / 白漆 / 大理石）、三个视角（鸟瞰、参考图同角度的客厅、平面图）。kit 自带的爆炸（建筑分层轴测）、剖切（1.25 m 水平剖切，墙体黑色截面）、X 光（墙体变透明）、标签、慢放、暂停。
  - 求解器：英雄数字是客厅平均照度（lx）= 日光（BRE 日光系数 × IES 多云天天光，太阳位置按 NOAA）+ 灯光（流明法，场景控制器按目标补足）。太阳就是 kit 的主光，方向和颜色跟着算出的太阳位置走；摄影棚随日落从纸白变成墨黑，室内的灯带、灯槽、射灯、落地灯按调光值亮起。
  - 没有做“故障”按钮：房间没有值得编造的故障（`3D_model/README.md` 要求不要硬加）。观影场景改为计算电视画面的对比度。
- **Anatomy**（`anatomy/`）：Fig 2「日光系数测试台」，一张约 60 个零件的等轴测图。
  - 灯箱当天空，玻璃加轨道上的纱帘当窗（T），敞口盒子当客厅，盒子内壁贴电视墙饰面样板（R），盒底 1:20 的小茶几上放光电池，接到读 0–15 % 的表盘上。
  - 盒子里有地砖格、小电视框、沙发和凳子，让它一眼看出是那间客厅；样板架上缺的那片，就是正在盒子里的那种饰面。
  - 按 1–3 换饰面、S 拉纱帘，或点下面的按钮；空闲时自动演示；reduced-motion 下不动画；浅色和深色两个主题。
- **Hairline**（`hairline/`）：材料样板盘。托盘里立着六片样板，每片靠自己的边认出来：纱帘的波浪边、布艺的锯齿边、胡桃木的纹理线、大理石的倒角和一条纹、地砖的厚片、黑钢的 L 形角钢。指针下的那片立起来，其余按距离错开倾倒；读数给出材料和日光模型用的反射率或透光率。静止时大理石那条纹是唯一的高亮。

## 集成与同步

- 测试台每次被用户改动（按钮或键盘），向父页面发送 `{ ns: "moshi", type: "daylight", finish, sheer, df }`；自动演示不发。
- 集成页核对来源窗口（必须是测试台的 iframe）和字段后，转发 `{ ns: "moshi", type: "set", finish, sheer }` 给 3D 模型；3D 模型核对消息来自父页面后，换电视墙材质、拉纱帘、重算照度。
- 3D 模型从不回发，所以没有回路；模型晚加载时，集成页在它 `load` 后补发最后一次状态。
- 测试台还会报告自己的内容高度（`type: "size"`），集成页据此设置 iframe 高度：`file://` 下各文件不同源，父页面量不到 iframe 内容。
- “快速跳转”按钮直接给 3D 模型发 `{ view, hour, scene }`。

## 参数来源与假设

| 量 | 数值 | 出处 |
|---|---|---|
| 地点与日期 | 吉隆坡 3.14°N 101.69°E，UTC+8，2026-10-14 | **假设**（演示用） |
| 太阳位置 | 日出约 07:02，正午高度 79°，日落约 18:57 | NOAA 公式；未计大气折射，实际日出日落各差约 5–10 分钟 |
| 室外天光 | 0.3 + 45 sin α klx；直射 127.5·e^(−0.80m) klx | IES Lighting Handbook 多云天公式；大气质量按 Kasten–Young |
| 平均日光系数 | DF = T·Aw·θ / (A(1 − R²)) | BRE（Littlefair）公式 |
| 窗、玻璃、纱帘 | 净玻璃 23.7 m²；T 0.62；纱帘 τ 0.55；θ 75° | **假设**（典型值） |
| 反射率 | 胡桃木 0.12、大理石 0.70、白漆 0.80、地砖 0.45、天花 0.85 | **假设**（常见材料典型值） |
| 结果 | DF 11.3 %（纱帘拉上 6.2 %）；白漆 12.1 %、大理石 12.0 % | 计算 |
| 灯具 | 灯槽 90 W / 9,000 lm，轨道灯 60 W / 5,100 lm，灯带 64 W / 5,760 lm，落地灯 8 W / 806 lm；UF 0.30 / 0.55 / 0.12 / 0.45；MF 0.8 | **假设**（目录典型值）；流明法 |
| 场景 | 日常 140 lx、会客 175 lx、观影约 17 lx、夜间约 10 lx | **假设** |
| 自动纱帘 | 窗上直射 > 8 klx 拉上、< 6 klx 拉开，0.6 m 出挑遮挡；日落后拉上 | **假设** |
| 电视 | 白 450 cd/m²、黑 0.09 cd/m²、屏幕反射 1.5 % | **假设** |

求解器的工作点（胡桃木饰面）：
- 13:00 纱帘拉开：日光约 5,040 lx，灯全关。
- 17:45 西晒，纱帘自动拉上：日光约 880 lx。
- 20:30 日常场景：灯光 140 lx、约 170 W；观影：17 lx、对比度约 3,400 : 1；白天拉上纱帘观影只有约 70 : 1。
- 测试台：换白漆，R 从 0.46 升到 0.51，DF 只多 7 %；拉上纱帘，DF 几乎减半——这间客厅的日光主要由窗决定。

**模型简化**：
- 照度是房间平均值，不是逐点光照计算；3D 里的光影只是示意（亮度按同一组数值调过，不是辐照度渲染）。
- 日光系数公式原本针对阴天；这里乘以多云天的天光，是常见近似。直射阳光只用来判断纱帘，不计入平均照度。
- 只有客厅参与计算；其他房间的灯按“天黑即开”示意。吊扇 140 rpm 是规格值。
- 测试台是示意，不按比例。

## 已完成的检查

- **3D 模型**（`shots/m-*`，GPU 无头 Chrome，1920 × 1080）：
  - 四轮截图审查：鸟瞰（白天、夜晚）、参考图同角度的客厅（傍晚、入夜、观影、正午）、平面图、爆炸。每轮修了发现的问题：取景、过亮的纱帘、太“裂纹”的大理石纹、过浅的布艺、侧栏文字压在场景上（客厅视角加了磨砂底）、kit 的 X 光会改写共用材质的不透明度（墙体层改用专用材质，玻璃和纱帘单独成层）、剖切截面反光（改为哑光黑）、平面图标签挤在左边（改为房间中心标注）、爆炸时 GTAO 条纹（爆炸时淡出 AO）、吊扇被裁（客厅视角放开仰角限制）。
  - 帧率：初版 21 fps；把 GTAO 采样减半、6 个面光源换成 4 个点光源、白天关掉 bloom 后，鸟瞰约 30–32 fps。最重的情形（夜里客厅视角、灯全开）仍只有约 16–22 fps，所以又加了自适应分辨率：每 1.5 秒低于 27 fps 就把像素比降 15 %（最低 0.7），高于 50 fps 再升回去，这个情形回到约 30–34 fps。无头环境的帧率波动较大，以上是多次测量的范围。
  - 求解器的数值与 `shared/daylight.mjs` 在 Node 里单独算出的值一致（上面的工作点）。
  - 控制台只有 kit 自带的 X4000 着色器警告（D3D11 编译 GTAO 时），未改 kit。
- **测试台**：线端检查在浅色、深色以及胡桃木 / 白漆 / 大理石、纱帘开 / 合各状态下都是 0 个悬空端；390 px 宽不横向滚动；控制台干净；4 倍近景看过盒子、样板、表盘。
- **样板盘**：validator 通过；look 检查的取景（覆盖 36 %）、读数、控制台、闪烁、响应都通过；动作序列里没有翻折或穿插。
- **集成页**（`file://`，1440 px 和 390 px，`shots/i-*`、`shots/p-*`）：
  - 测试台点“白漆”“拉上”后，3D 模型的状态变为白漆、纱帘拉上，面板显示 6.7 %。
  - 从 3D 模型的 iframe 伪造的消息被忽略。
  - 连续 12 次快速点击后，模型停在最后一次的状态（大理石、拉开，12.0 %）。
  - 快速跳转（观影）把模型切到客厅视角、观影场景、21:00。
  - 两种宽度都没有横向滚动；测试台 iframe 高度按它报告的内容高度设置。

## 遗留限制

- 3D 模型需要联网（three.js 和字体）；有独立显卡的浏览器会比无头环境流畅。手机上客厅视角是竖屏广角，侧栏只保留场景一行，纱帘和饰面在集成页的测试台里调。
- 布局、家具和尺寸是为这套公寓设计的，没有对应真实楼盘；沙发、凳子、灯具是按参考图形态做的简化模型。
- 参考图（`assets/reference.jpg`）是用户提供的，只用于对照，公开发布前请确认使用权。
- 按要求没有录制视频；`lab.autoFilm` 已配置，需要时可以用 `../machine/scripts/record.mjs` 录制（需要 Playwright 和 ffmpeg）。
- 所有标为“假设”的数值，在真实项目里应按选定的玻璃、窗帘、灯具和实测替换。
