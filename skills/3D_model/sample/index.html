夜画Night Canvas

一台床头树莓派。夜里用红外视觉记录翻身和睡姿，用声音模型识别鼾声和环境噪音；第二天早上，根据这些事件生成一幅画。画里每个元素都对应一个真实事件，可以当数据来读。原始画面当场丢弃，从不保存。

  • Pi 5 + Active Cooler
  • NoIR Camera Module 3
  • 850 nm 红外 ×6
  • YAMNet 声音事件
  • SDXL-Turbo · OnnxStream
01

床头设备

电子部分的交互式 3D 模型，按真实尺寸建模。拖动 CPU 负载 滑块，在夜间采集（红外灯开，约 30 %）和清晨生成（SDXL-Turbo 满载）之间切换；SoC 温度、功耗、风扇和主频都由热模型实时算出。键盘：E 爆炸 C 剖切 X X 光 L 标签 B 风扇停转 Space 暂停

需要联网：three.js 0.170 来自 jsDelivr，字体来自 Google Fonts。没有显示？单独打开 ↗

02

画就是数据

摄像头每一帧只被换算成一个数（相邻两帧变化像素的比例），麦克风只被换算成声级。数越过阈值，记录仪才落下一笔；画面当场丢弃。这里落下的每一笔都会实时同步到上面的设备（状态灯闪一下，事件数 +1），也会画进下面的示意画稿。

03

今晨画稿（示意）

上面同步过来的事件按先后从左到右排开，每一笔对应一个事件。这是程序化的构图示意，不是模型输出：真实设备会把同一份事件表写成提示词和构图，交给 SDXL-Turbo 在本机生成。

图例

  • 翻身 · 宽笔（宽度随运动能量）
  • 鼾声 · 点（一声一个）
  • 关门 · 细线
  • 安静 · 底色

小动作没有越过阈值，不会成为事件，所以画里没有它。

04

三个可视化各由一个技能生成，各自可以单独运行：

  • 设备 3D 模型：Machine 技能（three.js、PBR 材质、剖切、爆炸、X 光、热求解器）
  • 原理图：Anatomy 技能（等轴 SVG，源码 anatomy/build.mjs、model.mjs）
  • 引导插图：Hairline 技能（hairline/brush-pot.js，引擎与页面未改动）

同步接口：原理图向本页发送 { ns: "night-canvas", type: "event", kind, count }；本页核对来源和字段后转发给设备一次，设备从不回发，所以不会形成回路。
