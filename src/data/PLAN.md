# 马来西亚招聘数据采集（2026-10-24）

用户指定来源：Indeed、LinkedIn；输出全部位于 src/data。

现有项目：Vite / Three.js，Node.js 后端，JSON 文件持久化；careers.js 的 allCareers() 提供 13 个职业，SKILLS 提供技能 ID；已有 JSearch/n8n 市场流程。此次只收集及整理本地数据，不改游戏接口、不推送模拟市场统计。

采用用户要求的直接实施流程：

- [x] 导出现有职业、技能目录；为 13 个职业配置两个搜索别名。
- [x] LinkedIn：分页读取公开招聘搜索及详情；保存原始 HTML、请求日志、发现关系、预算及失败情况。遇到认证/禁止访问停止，不使用账户、代理或验证码绕过。
- [x] Indeed：直连已返回 HTTP 403。使用公开搜索索引发现职位，只保存可核实元数据及短摘要；明确标记为 indexed_excerpt，不冒充实时完整详情。保存查询及来源 URL。
- [x] 用 explore-data 检查本地表的粒度、重复、缺失、日期及覆盖；用 pandas-pro 生成独立清洗表。
- [x] 依据实际标题及职责映射现有职业；模糊岗位待分类。技能仅提取有原文证据的条目，区分否定、必须/加分、Java/JavaScript、React/React Native。
- [x] 生成 JSON、CSV、技能关联、职业覆盖、字段质量报告。没有连续历史时不计算增长趋势。
- [x] 验证重复导入、ID 映射、技能边界、地域筛选、缺失值、预算及部分失败。原始数据不覆盖。

完成结果：LinkedIn 402 则、Indeed 索引 57 则，共 459 则来源内去重广告，180 则可用完整描述，805 条技能关联，85 则待分类；13 个项目职业均有样本。7 项合成用例测试及 22 项真实数据离线验证通过。238 个原始文件在重放前后校验一致；232 个 HTTP 响应与采集时 SHA-256 一致。3 次请求失败均已记录，重试后 52 个搜索页与 180 个详情页读取成功。

限制：搜索结果有排序偏差、页数上限、索引时滞；仅统计所采集广告，不能外推全国职位数或招聘人数。原始数据留在本机，未知值保留 null。
