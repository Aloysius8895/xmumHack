We are seeking a PHP Developer to support and evolve business-critical platforms across an Australia and New Zealand portfolio for a global data and analytics organization. You’ll build new features, resolve production issues and help teams adopt AI-assisted delivery using tools like GitHub Copilot while working in balanced agile teams.

Responsibilities

  • Maintain and enhance existing PHP applications, including legacy, business-critical systems
  • Develop back-end components, application programming interfaces (APIs) and integrations aligned to enterprise standards
  • Investigate production issues, perform root cause analysis and drive incident resolution through to closure
  • Collaborate with cross-functional teams and distributed stakeholders to clarify requirements and plan delivery
  • Improve reliability through pragmatic refactoring, documentation and operational readiness practices
  • Support modernization initiatives such as migrations, platform upgrades and new service patterns as they emerge
  • Apply AI-assisted engineering tools to accelerate delivery and strengthen quality, with coaching and enablement support
  • Participate in on-call support coverage as needed to meet operational requirements

Requirements

  • PHP as a primary language with hands-on experience delivering and supporting production applications
  • Strong independent coding capability. While we encourage using AI tools for productivity, you must be able to write, evaluate and troubleshoot code autonomously rather than relying on AI to generate solutions
  • Legacy systems exposure with ability to navigate complex codebases and improve them safely
  • APIs experience, including building, integrating and supporting back-end services
  • Problem-solving ability to troubleshoot incidents, analyze logs and restore service quickly
  • Agile delivery experience working in Scrum or Kanban teams
  • Clear communication in spoken and written English for distributed collaboration

Nice to have

  • Java exposure in mixed PHP and Java environments
  • Automated testing practices in PHP (unit, integration, regression)
  • Financial services domain exposure such as banking
  • Spec-Driven Development (SDD) and Test-Driven Development (TDD) experience
