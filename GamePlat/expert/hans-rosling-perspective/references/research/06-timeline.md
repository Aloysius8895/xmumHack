# 06 时间线 · Hans Rosling（快速档附带）

| 时间 | 事件 |
|---|---|
| 1948 | 生于瑞典 Uppsala |
| 1967–1974 | Uppsala 大学学统计学和医学 |
| 1971–1972 | 印度之行；在 Bangalore St. John's Medical College 学公共卫生 |
| 1976 | 取得执业医师资格 |
| 1979–1981 | 莫桑比克北部 Nacala 区医疗官 |
| 1981 | 开始调查 konzo 暴发 |
| 1984–1994 | 瑞典国际发展合作署（Sida）顾问：初级卫生保健，后转 HIV |
| 1986 | Uppsala 博士（木薯、氰化物与流行性痉挛性截瘫）|
| 1993 | 参与创建瑞典无国界医生 |
| 1997 | Karolinska 学院国际卫生教授 |
| 2001–2007 | Karolinska 国际卫生部门主任 |
| 2005 | 与儿子 Ola、儿媳 Anna 创立 Gapminder 基金会，开发 Trendalyzer |
| 2006 | TED「The best stats you've ever seen」；瑞典怀疑论者协会「年度启蒙者」|
| 2007-03 | Google 收购 Trendalyzer，后推出 Motion Chart |
| 2010 | BBC Four《The Joy of Stats》|
| 2012 | Time 100；TED「Religions and babies」|

| 2014 | 与 Ola 合讲 TED；10 月赴利比里亚协助埃博拉数据工作 |
| 2015 | BBC《Don't Panic: How to End Poverty in 15 Years》；丹麦 DR2 访谈用苹果解释难民流向 |
| 2016 | 确诊胰腺癌 |
| 2017-02-07 | 在 Uppsala 去世，68 岁 |
| 2018 | Factfulness 出版 |
| 2020 | 回忆录 How I Learned to Understand the World 出版 |

## 时效说明

他 2017 年去世。对 2017 年后的工具（现代 BI、LLM、AI 分析助手等）和事件，他没有任何公开立场，人物卡里必须当作「框架推断」处理。
